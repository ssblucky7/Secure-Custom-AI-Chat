Privacy Policy

Last updated: January 2025. This policy applies to the Secure Custom AI Chat software and any instance you self-host.

🔒
Short version: No accounts. No tracking. No server-side conversation storage. Your chat history lives only in your browser's localStorage.

Data We Collect

The Secure Custom AI Chat software itself does not collect, transmit, or store any personal data on behalf of the software project. As a self-hosted application, each deployment is independently operated.

The software server:

  • Does not log conversation content, messages, or AI responses.
  • Does not create user accounts or require registration.
  • Does not set cookies or use tracking pixels.
  • Does not transmit usage data to any third party.
  • Does not store your API keys in any database (keys are in-memory environment variables only).

Standard web server access logs may be generated by the Node.js process or your reverse proxy, containing request timestamps, HTTP method, path, status code, and IP address. These are standard infrastructure logs and do not contain conversation content.

Conversation Data

Your conversation history is stored exclusively in your browser's localStorage under the key secureCustomAIStateV1. This data never leaves your device unless you explicitly export it.

When you send a message, it is transmitted to the server and forwarded to the AI provider you have configured (e.g., OpenAI, Anthropic). The server does not persist this data after the request completes. Your messages are subject to the privacy policy of your chosen AI provider.

API Keys

In default mode (ALLOW_USER_PROVIDERS=0), API keys are stored in server environment variables and never transmitted to clients.

In user-provider mode (ALLOW_USER_PROVIDERS=1), user-entered API keys are stored in browser localStorage. They are transmitted over HTTPS to the server with each chat request and are not logged or stored by the server.

Third-Party AI Providers

When you use this application, your messages are sent to the AI provider you configure. Each provider has its own privacy policy governing how they handle your data:

  • OpenAI: openai.com/privacy
  • Anthropic: anthropic.com/privacy
  • OpenRouter: openrouter.ai/privacy
  • Groq: groq.com/privacy-policy
  • Ollama (local): Data does not leave your machine.

Children's Privacy

This software is not directed to children under 13. We do not knowingly collect information from children under 13.

Changes to This Policy

As open-source software, this policy applies to the default configuration of the software. Operators who deploy the software may have additional policies for their specific deployments.

Contact

For questions about privacy in the context of the open-source software, please open an issue in the project repository.
