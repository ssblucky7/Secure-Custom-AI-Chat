Release History

What's Changed

All notable changes, new features, bug fixes, and security improvements to Secure Custom AI Chat.

v2.0.0 2025-07 Latest

v2.0.0 — Major SEO & Content Update

✨ New

  • Full SEO landing site: /features, /providers, /security, /faq, /docs, /about, /privacy, /terms, /changelog pages.
  • Shared page.css stylesheet with dark theme, hero, cards, feature grid, FAQ accordion, provider table, alert boxes, and responsive nav.
  • OG image (/og-image.svg) for social sharing previews.
  • Structured data (JSON-LD) on all pages: WebSite, SoftwareApplication, FAQPage, AboutPage, BreadcrumbList.
  • sitemap.xml listing all pages for search engine indexing.
  • robots.txt with sitemap reference and crawl rules.
  • Breadcrumb navigation on all SEO pages.
  • FAQ page with expandable <details>/<summary> accordion with structured data.
  • Providers page with full comparison table: protocol, base URL, suggested models, preset status.
  • Security page with layered security model documentation.
  • Docs page with complete installation, configuration, and deployment guide.

🔒 Security

  • No security regressions. All existing server-side security features preserved.
  • New pages use page.css with no external dependencies.
  • Server routes for .html pages serve via Express static middleware, respecting existing CSP headers.

♿ Accessibility

  • All new pages include skip links, aria-current on active nav items, semantic landmarks, and focus-visible outlines.
  • FAQ accordion uses native <details>/<summary> for keyboard accessibility without JavaScript.
v1.5.0 2025-04

v1.5.0 — Provider Presets & Model Chips

✨ New

  • Provider preset dropdown with one-click configuration for ZenMux, OpenAI, Anthropic, OpenRouter, Groq, Together AI, DeepSeek, Mistral, Ollama, and LM Studio.
  • Multi-model chip UI — add multiple model IDs, switch between them per conversation.
  • "Load models" button fetches available models from the provider's /models endpoint.
  • ZenMux as default provider preset with free model options.
  • Anthropic Messages API support with server-side SSE normalization.

🐛 Fixed

  • Streaming no longer hangs on Anthropic message_stop events.
  • Model dropdown now correctly resets when provider preset changes.
v1.4.0 2025-02

v1.4.0 — PWA & Offline Support

✨ New

  • Service worker with app shell caching for offline loading.
  • Web App Manifest with shortcuts, icons, display mode, and theme color.
  • PWA install prompt detection and banner UI.
  • Safe-area inset CSS variables for notched mobile devices.
v1.3.0 2024-12

v1.3.0 — Security Hardening

🔒 Security

  • SSRF protection with full private IP range blocking (IPv4 + IPv6).
  • DNS resolution pre-check for provider hostnames.
  • Prototype pollution sanitization on all incoming JSON bodies.
  • Secret redaction in error messages and server logs.
  • Request body size limit (2MB).
  • AbortController 60s timeout on all provider requests.
  • Rate limiting: 120/min API, 30/min chat.
  • Helmet security headers including CSP, X-Frame-Options, and Referrer-Policy.
v1.0.0 2024-09

v1.0.0 — Initial Release

✨ New

  • Server-side API key proxy (Express + Node.js native fetch).
  • Real-time SSE streaming with requestAnimationFrame rendering.
  • Conversation history in localStorage (up to 30 conversations).
  • Markdown rendering: headings, bold, italic, code blocks, lists, blockquotes.
  • Conversation export as Markdown.
  • System prompt configuration.
  • Regenerate response functionality.
  • Responsive dark theme UI.
  • Keyboard navigation and accessibility (ARIA, skip link, focus indicators).
