Why Secure AI Chat

Everything you need, nothing you don't

🔒

Server-side keys

API keys live in your .env file and are never sent to the browser. Zero client-side exposure.

⚡

Streaming responses

Real-time token streaming via Server-Sent Events. Fast, responsive, no polling.

🌐

12+ providers

OpenAI, Anthropic, Groq, Together AI, DeepSeek, Mistral, Ollama, LM Studio and more.

📱

Installable PWA

Install as a native-feeling app on any device. Works offline for static assets.

🏠

Fully self-hosted

Runs on Node.js 18+. Deploy on any VPS, Raspberry Pi, or local machine in minutes.

🛡️

SSRF protection

Strict DNS-level validation blocks server-side request forgery against private networks.

Quick Start

Up and running in 60 seconds

git clone https://github.com/youruser/secure-custom-ai-chat.git
cd secure-custom-ai-chat
npm install
cp .env.example .env   # add your API key
npm start              # open http://localhost:3000
