Security

Security Features

🔑

Server-Side API Key Proxy

In default mode, your API key is stored in server environment variables and never sent to the browser. The server acts as an authenticated proxy between your browser and the AI provider.

🛡️

SSRF Protection

Provider URLs are validated against private IP ranges (10.x, 172.16-31.x, 192.168.x, loopback, link-local, CGNAT) and resolved via DNS to block server-side request forgery attacks.

🚦

Rate Limiting

Built-in rate limiting: 120 requests/minute for the API, 30 requests/minute for chat. Uses express-rate-limit with standard RFC 6585 rate-limit headers.

🪖

Security Headers (Helmet)

Content Security Policy, X-Frame-Options, X-Content-Type-Options, Referrer-Policy, and more — configured via Helmet for defense-in-depth protection.

🧹

Prototype Pollution Prevention

All incoming JSON bodies are sanitized to strip __proto__, constructor, and prototype keys before processing.

🔇

Secret Redaction in Errors

All error messages and server logs are sanitized to redact API keys and sensitive values before they could be exposed via error responses.

AI Features

AI & Chat Features

⚡

Real-Time SSE Streaming

Responses stream token-by-token via Server-Sent Events. The UI uses requestAnimationFrame batching for smooth, non-blocking rendering even at high token rates.

🔄

Dual API Protocol Support

Supports both OpenAI-compatible (chat/completions) and Anthropic Messages API protocols. The server normalizes Anthropic SSE events to a consistent format.

🏪

12+ Provider Presets

One-click presets for ZenMux, OpenAI, Anthropic, OpenRouter, Groq, Together AI, DeepSeek, Mistral, Ollama, and LM Studio. Custom URL support for any compatible provider.

🤖

Model Management

Load available models from provider API, add multiple models as chips, and switch between them per-conversation. Supports any valid provider model ID.

💬

System Prompt Control

Customize the system prompt from the settings dialog. Supports up to 4,000 characters. Automatically prepended to every conversation.

🔁

Regenerate Responses

Click "Regenerate" on any assistant message to re-run the request from that point, with the same conversation context.

UI & UX

Interface Features

📝

Markdown Rendering

Assistant responses render headings (h1–h3), bold, italic, inline code, fenced code blocks with language labels, ordered and unordered lists, blockquotes, and clickable links.

💾

Conversation History

Up to 30 conversations are saved to browser localStorage. Conversations are sorted by last-updated time. History persists across browser restarts.

📤

Export Conversations

Download any conversation as a formatted Markdown file (.md) with role headers for each message. Filename is auto-generated from the conversation title.

📱

Progressive Web App

Install the app on iOS (Add to Home Screen), Android, or desktop. The service worker caches the app shell for offline access. Web App Manifest enables standalone mode.

♿

Accessibility

Skip link, ARIA roles, live regions for status updates, focus-visible outlines, prefers-reduced-motion support, semantic HTML, and keyboard navigation throughout.

📐

Responsive Design

Fully responsive layout from 320px mobile to wide desktop. Mobile sidebar with backdrop overlay. Safe-area inset support for notched devices. Touch-friendly controls.

Configuration

Configuration Options

All configuration is via environment variables in your .env file. No code changes required.

🌐

Provider URL & Key

Set AI_API_URL and AI_API_KEY to configure a default server-side provider. These are never exposed to clients.

🎛️

User Provider Mode

Set ALLOW_USER_PROVIDERS=1 to let users supply their own provider URL and API key. The server still proxies all requests.

🏠

Local Model Access

Set ALLOW_PRIVATE_PROVIDER_URLS=1 to allow connections to localhost providers like Ollama or LM Studio during development.

⚖️

Token Limits

Set AI_MAX_TOKENS_LIMIT to cap the maximum tokens per request (1–100,000). Default is 8,192. The UI enforces this server-defined limit.
