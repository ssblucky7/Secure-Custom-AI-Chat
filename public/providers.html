Custom Providers

Custom Provider Support

Any provider that supports the OpenAI chat/completions format or the Anthropic Messages API works with Secure Custom AI Chat.

To add a custom provider:

  1. Open the Settings dialog in the app.
  2. Select Custom provider from the Provider preset dropdown.
  3. Choose the appropriate API Protocol (OpenAI Compatible or Anthropic Messages).
  4. Enter the Base URL for your provider (e.g., https://your-litellm-proxy.com/v1).
  5. Enter your API key if required.
  6. Enter or load the model ID.
  7. Click Save setup.

Custom providers that work well include: LiteLLM proxy, OpenLLM, LocalAI, text-generation-webui with OpenAI extension, and any self-hosted vLLM instance.

Protocol Notes

API Protocol Details

🟢

OpenAI Compatible

Uses POST /v1/chat/completions with a Bearer authorization header. Supports streaming via SSE. Compatible with any provider that follows the OpenAI API spec.

🟠

Anthropic Messages

Uses POST /v1/messages with an x-api-key header. The server normalizes Anthropic's content_block_delta SSE events to the same format as OpenAI streams, so the frontend handles both identically.

✦
Secure AI Chat

Self-hosted, server-side proxied AI chat. Works with OpenAI, Anthropic, OpenRouter, Groq, Ollama and more.
